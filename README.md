# Artigo-SEMATEC
Avaliação de Estratégias de Aumento de Dados na MobileNetV3-Large para Classificação de Alterações Foliares em Algodoeiro

O artigo científico que conquistou o terceiro lugar como melhor artigo da SEMATEC 2026 (Semana Acadêmica de Tecnologia). Além do reconhecimento e da premiação no evento, o trabalho foi publicado oficialmente nos anais da SBC OpenLib (SOL)
